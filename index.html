口径与约束

硬约束（筛掉 90% 候选）

  • C1 一人交付：全链路靠「我一个人 + AI」跑完，获客线上自助、交付靠产品本身。排除线下签单 / 销售团队 / 地推 / 人工一对一 / 招投标 —— 与主体是个人还是公司无关。
  • C2 主体：现有「重启实业(深圳)」公司主体，或个人主体。
  • C3 变现：线上自助付费，或广告变现。
  • C5 资金：启动资金几万块量级。
  • C8 市场：国内优先。

扫描口径（已收敛）

  • 应用商店只扫中国区（cn 单区；us/jp/kr 暂缓，可恢复）。
  • 只考虑移动端：iOS / Android / 小程序 / H5；Windows / macOS / Steam 撤下。
  • 免费榜必须与付费榜同扫。

扫描渠道

  • 应用商店：App Store、Google Play。
  • 小红书（重点）：搜索 + 笔记，需求常常先在这里被暴露；须能从笔记里提取可用信息。
  • 社交媒体：微博、微信、抖音。
  • 论坛社区：知乎、V2EX。
  • 第三方数据：questmobile、阿拉丁指数、点点数据、新榜、七麦、appgrowing、蝉大师。
